# Онбординг (y-adaptaion) — отчёт о внедрённом функционале

**Продукт:** демо-кабинет адаптации новичка.  
**Стек:** Vite + React, mock API в памяти сессии (без бэкенда и без сохранения задач после reload).  
**Демо-аккаунты:** `employee@example.com` — сотрудник (Алина Ковалева); `admin@example.com` — HR (Олег Белов). Пароль: `password`.  
**Роли:** Сотрудник · HR (admin).

Источники: коммиты от 15.09.2026, планы и рабочие сессии от 24.09.2026, 30.09.2026 и 08.10.2026 (дни 4 и 5).

---

## День 5 — 8 октября 2026

HR сам ведёт контент: материалы, шаблоны, справочники и данные сотрудника. Вместо удаления — архив. Все поля дат — кастомный DatePicker.

### HR

| Функция | Что умеет пользователь |
| --- | --- |
| Каталог материалов `/admin/materials` | Поиск, фильтр «Активные / Архив», добавить, изменить, отправить в архив и вернуть |
| Форма материала | Название, ссылка (проверка `https://`), тип, категория, длительность, описание |
| Редактор шаблона `/admin/templates/new`, `/$id` | Этапы с днями «с — по», задачи по дням, приоритет, исполнитель (сотрудник / руководитель / наставник), материалы; порядок этапов и задач; живое превью |
| Копия шаблона | «Копировать» открывает редактор с «(копия)» в названии |
| Проверки шаблона | День задачи в пределах этапа, конец этапа не раньше начала, в этапе есть задачи; последний активный шаблон нельзя архивировать |
| Снимок плана | План сотрудника фиксируется при создании: правка шаблона не меняет уже назначенные планы |
| Справочники `/admin/directories` | Руководители, наставники, отделы: добавить, переименовать, архив; уникальное название отдела |
| Переименование | Новое ФИО / название сразу видно в карточках, задачах и фильтрах |
| Архив в справочниках | Текущие сотрудники сохраняют человека или отдел (с пометкой «в архиве»), для новых назначений они недоступны |
| Данные сотрудника на карточке | Имя, фамилия, email (уникальный), должность, отдел, дата выхода |
| Сдвиг даты выхода | Сроки открытых задач и этапов сдвигаются на ту же разницу; подсказка «сдвинутся на +N дн.»; запись «Профиль изменён» в истории |
| DatePicker | Месяц с навигацией, «Сегодня», выделение текущей даты, клавиатура (стрелки, PageUp/PageDown, Enter, Escape) |

### Сотрудник

| Функция | Что изменилось |
| --- | --- |
| Уведомления | «Сдвинута дата выхода» и «Обновлены данные профиля» при смене даты, должности или отдела |
| Материалы | Видит новые материалы HR; архивные пропадают из базы знаний, но остаются в задачах, где уже привязаны |
| План | Не меняется, если HR правит исходный шаблон |

**Проверено в браузере:** валидация и сохранение всех форм, архив и возврат материала, снимок плана при правке шаблона, переименование и архив наставника и отдела, сдвиг даты выхода с уведомлением, вход нового сотрудника и блок `/admin/*`. `tsc`, `eslint` и `vite build` — без ошибок.

## День 4 — 8 октября 2026

Полный цикл адаптации у HR: от заведения новичка до диалога по задачам и журнала изменений.

### HR

| Функция | Что умеет пользователь |
| --- | --- |
| Каталог шаблонов `/admin/templates` | Видеть шаблоны планов: этапы, задачи по дням, длительность |
| Добавить сотрудника `/admin/employees/new` | ФИО, email, должность, отдел, дата выхода, руководитель, наставник, шаблон; превью плана; валидация формы |
| Автосборка плана | Сроки задач = дата выхода + день из шаблона; задачи «Руководитель/Наставник» назначаются на выбранных людей |
| Команда адаптации на карточке | Сменить руководителя и наставника; открытые задачи этих ролей переназначаются автоматически |
| Страница задачи сотрудника | Редактировать название, срок, приоритет, описание; снять задачу с плана |
| Привязка материалов к задаче | Поиск и выбор материалов при добавлении и редактировании задачи |
| Вопросы новичков | Счётчик «с вопросами» в сводке, фильтр «С вопросами», бейдж «Вопросы · N»; ответ в обсуждении задачи |
| История на карточке | Создание, команда, правки, сдвиг/снятие задач, напоминания, вопросы и ответы; переход «К задаче» |

### Сотрудник

| Функция | Что изменилось |
| --- | --- |
| Вопрос по задаче | Обсуждение на деталке задачи; HR получает уведомление |
| Материалы в задаче | Видит материалы, которые привязал HR |
| Наставник | В профиле и в карточке «Помощь» на главной и на этапе |
| Уведомления | О правках задачи, смене команды и ответах HR |

**Принципы:** все записи истории и уведомлений создаются в одном месте mock API; данные по-прежнему живут до reload вкладки.

## День 3 — 30 сентября 2026

Кабинет HR: контроль рисков и правки плана новичка. Сотрудник только получает результат в своём списке задач и inbox.

| Функция | Роль | Что умеет пользователь |
| --- | --- | --- |
| Поиск и фильтры новичков (имя, отдел, риск, этап) | HR | Найти человека в списке `/admin/employees` |
| Сводка: сколько новичков, с просрочкой, средний %, на этапах | HR | Оценить картину по команде |
| Бейдж «Просрочено · N» на карточке | HR | Видеть риск, не открывая план |
| Напоминание о просрочках (антидубль ~10 мин) | HR → Сотрудник | HR жмёт «Напомнить»; сотрудник видит уведомление |
| Личный inbox уведомлений (`userId`) | Сотрудник / HR | Каждый видит только свои |
| Вёрстка карточек списка (зазоры, бейдж не слипается) | HR | Читаемые ФИО, должность, %, этап |
| Добавить задачу в этап | HR → Сотрудник | Форма на карточке новичка; задача в плане и в `/tasks`; уведомление «В план добавлена задача» |
| Сдвинуть срок | HR → Сотрудник | На просроченных и незакрытых (в т.ч. будущие этапы); уведомление «Срок задачи обновлён» |
| Снять задачу с плана | HR → Сотрудник | Невыполненные шаблонные и custom; выполненные нельзя; уведомление «Задача снята с плана» |
| Пустой этап остаётся в таймлайне как completed | HR / Сотрудник | План не «дырявится», открывается следующий этап |
| Завершать чужие задачи нельзя | HR | Кнопки «Завершить» у HR нет |
| Редирект с `/admin/employees` | Сотрудник | По-прежнему на главную |

**Не делали в этот день:** создание новичка, смена наставника, шаблоны, привязка материалов, удаление выполненных.

## Сводка «кто что умеет» на 08.10.2026 (после дня 5)

**Сотрудник:** свой план, задачи (в т.ч. завершение), материалы, профиль с наставником, вопросы по задачам, уведомления (правки плана, команда, ответы и напоминания от HR). Админку не видит.

**HR:** список и фильтры (в т.ч. «С вопросами»), сводка рисков, создание новичка по шаблону, правка данных сотрудника со сдвигом даты выхода, смена команды, добавление / редактирование / сдвиг / снятие задач с материалами, ответы на вопросы, история изменений. Ведёт контент: материалы, шаблоны (создание, правка, копия), справочники руководителей, наставников и отделов; вместо удаления — архив. Завершать чужие задачи нельзя.

**Общее:** mock, данные до reload вкладки; сессия логина в `localStorage`; планы сотрудников — снимки шаблонов; все даты выбираются кастомным DatePicker.
